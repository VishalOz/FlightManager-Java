# ✈️ FlightManager-Java

A simple **console-based Flight Ticket Management System** built in Java, demonstrating core Object-Oriented Programming (OOP) concepts like encapsulation, abstraction, and modular design.

---

## 📌 Features

- ✅ Add and view flights
- ✅ Book and cancel flight tickets
- ✅ Handle basic passenger information
- ✅ View all booked tickets
- ✅ Console-based user interface

---

## 🧰 Tech Stack

- Java (JDK 8 or higher)
- Standard Java libraries (`Scanner`, `Map`, `List`)

---

## 🧱 OOP Principles Used

| Concept         | Application                          |
|-----------------|--------------------------------------|
| Encapsulation   | Private class fields with getters/setters |
| Abstraction     | FlightManager and TicketManager manage system logic |
| Inheritance     | (Optional extension: shared User class) |
| Polymorphism    | (Expandable with interfaces/method overrides) |
